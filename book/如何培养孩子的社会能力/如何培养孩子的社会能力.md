# 《如何培养孩子的社会能力》整理笔记（详细版）

**作者核实**：**Myrna B. Shure（玛娜·舒尔）** 等；中文版常见与 **ICPS（I Can Problem Solve）** 人际认知问题解决课程相关。樊登/帆书书单曾推介。具体译者、出版社以版权页为准。  
**适用读者**：9个月宝宝父母——先建情绪语言与视角萌芽，【偏3岁以上】才进入完整提问链。  
**写作说明**：据ICPS公开介绍与读书笔记整理，无盗版全文。

**年龄标签**：【现在可用 9月–1岁】/【1–3岁】/【偏3岁以上】

---

## 核心一句话

社会能力可以教：不是替孩子打架或讲大道理，而是教他**想出多种解决办法、预见后果、理解他人感受**（ICPS）。低龄先下「感受词」与「等待/轮流」的种子。

---

# 一、ICPS 核心：提问，不给唯一答案

## 原则

家长少说「你应该……」，多问：「发生了什么？你有什么感觉？他可能有什么感觉？你还能怎么做？如果那样会怎样？」  
孩子练习的是思维灵活性，不是背标准答案。

## 年龄适配

- **【偏3岁以上】**：完整提问链最适用。  
- **【1–3岁】**：缩成两问——「你怎么了？」「我们还可以怎样？」（给两个具体选项）。  
- **【现在可用】**：不提问链；练感受命名+示范轮流（你滚球给我，我滚回去）。

**验证**：冲突后他是否开始冒出第二个办法，而不是只会打或哭。

---

# 二、情绪语言是社会能力的地基

不会命名感受，就难谈「他可能伤心」。  
【现在可用】：「你急」「你喜」「你怕」配表情。  
【1–3岁】：看绘本指「他哭了，他难过吗？」  
叠《父母的语言》《如何说…》。

---

# 三、视角采择：他心里也有故事

【1–3岁】萌芽：抢玩具时「弟弟也想要；我们的办法是……」  
【偏3岁以上】：角色扮演、玩偶对话。  
【现在可用】：你抱他时也对另一大人说「爸爸等一下」——示范「别人也有等待」。

**书中未见**：九个月「共情测验」通过标准。

---

# 四、解决办法风暴（安全内）

冲突时先拦伤害，再问办法。家长忍住秒给答案。  
若卡死，提供两个选项当脚手架，仍让他选。【1–3岁】  
【现在可用】：两个玩具都可够——「看，还有一个」代替训「要分享」（分享【偏3岁以上】更真实）。

---

# 五、后果思维

「如果打，他会怎样？你会怎样？」【偏3岁以上】  
【1–3岁】：极简「打会疼；我们拍垫子」。  
【现在可用】：自然反馈——扔碗响、你皱眉、你移开——因果在经验里，不在说教。

---

# 六、实践总表

| 能力 | 做法 | 年龄 | 验证 |
|------|------|------|------|
| 感受词 | 命名自己的与故事中的 | 现在起 | 词汇出现 |
| 轮流 | 滚球、推车来回 | 现在–3 | 等待秒数↑ |
| 二选一 | 冲突给两安全方案 | 1–3 | 少僵持 |
| 提问链 | 完整ICPS | 偏3+ | 自发多方案 |
| 视角 | 「他也想…」 | 1–3起 | 少只顾自己抢 |

# 七、一句话

社会能力不是「乖」；是会感受、会想办法、会顾及他人。九个月先从命名与来回游戏播种，提问链留给会说话的夏天。

---

# 扩展实践：滚球轮流（社会能力种子）

每天5分钟：你滚→等→他动→你再滚。语言：「轮到你……轮到我。」  
**【现在可用】**：即使他不会故意滚回，你仍示范等待。  
**验证**：等待时哭闹是否渐短。

# 扩展实践：绘本感受猎人【1–3岁】

每页多问：「他脸上怎样？可能心里怎样？接下来可以怎样？」不强迫标准答案。  
**【现在可用】**：你指着图说感受词即可。

# 扩展实践：冲突二选一脚手架

抢物时：选项A「用沙漏轮流」；选项B「换一个一样的」。你不问「应不应该抢」的道德课，先练办法。  
**【偏3岁以上】**：再加「还有别的办法吗？」

把前面的原则再压进今天：选一个场景，只练一个动作，写一行观察。

1. **场景选择**：喂养、睡眠、换尿布、爬行探索、与客相处、夫妻换手——挑今晚最可能炸的一个。  
2. **动作**：只用书中一种工具（诚实短句 / Yes and / 四步里的观察 / 无条件爱宣言 / 课题分离自问 / ICPS式二选一的萌芽 / 身体放松）。  
3. **记录**：他的反应（哭峰长短、是否靠近、是否再试）；你的身体（肩是否降下来）。  
4. **验证标准**：不是「一次成功」，而是「你是否比上周少用羞辱/威胁/评判」。  
5. **九个月提醒**：语言少、重复多、身体在场大于道理；无效时先查饿困病，再查方法。  
6. **伴侣同步**：用一句话告诉对方你今晚只练什么，避免互相拆台。  
7. **收尾**：睡前三十秒——「今天我守住了____，明天我想改____。」

**【补充例子（非书中）】**：若今晚场景是「洗澡哭」——先连连接（毛巾预暖、你的脸出现在他视野），再办事；把「快点洗完」改成「我们还有肚皮、还有小脚」。  
**【书中未见】**：精确分钟配方；请按自家节奏微调。

# 扩展实践：家庭「社会能力」微课（无屏幕）

每周固定一件事当微课，不考试：

1. **打招呼**：家人进门，你示范「回来了」并轻拍他手【现在可用】；【1–3岁】鼓励他挥手。  
2. **等待**：微波炉叮一声前一起数「等等」；把等待和生活节奏绑在一起。  
3. **求助**：你假装拿不到，说「帮妈妈」——让他体验「我能帮人」【1–3岁】。  
4. **道歉示范**：你撞到他，认真说对不起并轻抚——社会能力首先是被这样对待过。  
5. **冲突回放**：睡前用玩偶演白天抢玩具，问「还可以怎样」【偏3岁以上】；【1–3岁】只演两个办法。  

**验证**：真实冲突里是否出现微课里演过的办法；你是否少替他「打赢」。  

**【补充例子（非书中）】**：游乐场抢滑梯——先保证安全，再蹲下问「你想滑；他也想滑；办法是轮流还是找另一个？」若太小，你当旁白示范轮流。  
**书中未见**：游乐场专用脚本原文；此为ICPS精神应用。

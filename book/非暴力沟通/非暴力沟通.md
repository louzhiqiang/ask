# 《非暴力沟通》整理笔记（详细版·亲子向）

**作者核实**：**Marshall B. Rosenberg（马歇尔·卢森堡）**；中文版《非暴力沟通》，多版次（华夏出版社等），译者常见为阮胤华等（以版权页为准）。樊登/帆书有解读。核心为观察–感受–需要–请求四步骤。  
**适用读者**：约9个月宝宝父母（把NVC当父母自我语言与即将到来的幼儿对话骨架）。  
**写作说明**：据公开教程、读书笔记整理，无盗版全文。亲子场景为应用；非书中例子标「补充例子（非书中）」。

**年龄标签**：【现在可用 9月–1岁】/【1–3岁】/【偏3岁以上】

---

## 核心一句话

非暴力沟通（NVC）用**观察、感受、需要、请求**代替评判、指责、命令与要挟，让连接先于纠正。对婴儿：你先对自己与伴侣用四步；对他用简化的「看见+需要+行动」。

---

# 一、四步骤详解

## 1. 观察（Observation）——不掺评判

- **原则**：只说摄像机能拍到的，不说「你总是」「你故意」。  
- **书中精神**：观察与评价混在一起时，听者容易听到批评而反抗。  
- **亲子例**：  
  - 评判：「你真闹！」  
  - 观察：「你已经哭了大约两分钟，腿在蹬。」【现在可用】对内观察；对外可短说「你在哭」。  
- **验证**：对方（伴侣）是否少立刻辩解。

## 2. 感受（Feeling）——是感受不是想法

- **原则**：「我觉得你不爱我」是想法；「我难过、焦虑、疲惫」是感受。  
- **亲子**：替孩子猜感受要谦虚，用试探：「你是不是很挫败？」【1–3岁】；婴儿则用表情语气：「好难受啊。」【现在可用】  
- **验证**：命名后哭闹强度是否有短暂「被看见」的停顿。

## 3. 需要（Need）——感受底下的普适需要

- **原则**：需要是普适的（安全、休息、被看见、自主、玩耍……）；策略是满足需要的一种方式。哭要抱——需要可能是连接/安全；策略是抱、是嗓音、是乳房，可变。  
- **验证**：你能否说出「需要」而不只说「他必须立刻睡」。

## 4. 请求（Request）——具体、可完成、非命令

- **原则**：请求允许说「不」；命令带惩罚威胁。  
- **亲子**：【偏3岁以上】「你愿不愿意现在把车子收进箱子，还是五分钟闹钟响再收？」  
- 【现在可用】：请求主要对伴侣——「你能不能抱他十分钟，我喝水？」；对婴儿是行动响应，不是谈判。

# 二、父母内在的「长颈鹿」与「豺狼」（公开比喻）

卢森堡常用长颈鹿（心大、温和）与豺狼（指责习性）比喻。养育中豺狼句：「你怎么又……」「我为你做了这么多……」。长颈鹿句：观察+感受+需要+请求。

**【现在可用】**：夜哭第三轮，豺狼是「你故意整我」；长颈鹿是「我观察到他又醒了；我感到耗竭；我需要休息与支持；我请求换班」。——先对自己与伴侣说完，再温柔对孩子。

**验证**：你是否少把恶意动机安在婴儿头上。

---

# 三、倾听：先陪感受，再解决问题

NVC强调倾听他人的观察/感受/需要，而不是立刻建议或否定。  
叠《如何说孩子才会听》：先复述感受。  
【1–3岁】：「油瓶倒了，你很吃惊，又有点害怕。」再一起擦。  
【现在可用】：先抱够，再换尿布——顺序=连接先于事务。

---

# 四、道歉与修复的NVC版

暴力道歉：「都是你哭得我才凶的。」  
NVC向：观察自己的行为+感受+需要+请求原谅与下一步。「妈妈刚才喊得很大声。妈妈很累、很怕失控。妈妈需要安静一点的方式。对不起。妈妈抱抱你。」【现在可用】语气+拥抱即可；【1–3岁】可加短句。

**验证**：修复后孩子是否重新靠近。

---

# 五、与界限的关系：NVC不是无底线

可以有保护性强制（拉回马路），同时心中完成四步：观察危险、感受害怕、需要安全、请求「我们拉手走」（幼儿）。婴儿：身体移开+安抚，不羞辱。

**书中未见**：儿科睡眠训练步骤；请勿把NVC误当医疗协议。

| 步骤 | 父母对自己/伴侣 | 对婴儿【现在可用】 | 对幼儿【1–3岁】 |

# 七、豺狼句 → 长颈鹿句对照（亲子高频）

| 豺狼 | 长颈鹿方向 |
|------|------------|
| 「你总是哭」 | 「晚上已经醒了三次；我很累；我需要支持」 |
| 「你故意泼饭」 | 「饭在桌上/地上；你可能想自己舀；我们需要衣服干净一点——用围嘴再试」【1–3岁】 |
| 「再闹不要你了」 | 「妈妈不会不要你；妈妈现在需要安静抱」【现在可用】禁抛弃威胁 |
| 「你怎么这么烦」 | 「我心烦、需要喘气；你需要陪伴——我们换爸爸抱一下」 |

**【补充例子（非书中）】**：疫苗后哭——观察「针刚打完」；感受「你很痛很怕」；需要「安慰」；请求对护士「请再给一分钟安抚」——父母用NVC对系统，对孩子用身体安慰。

|----|------|

| 三 | 为同一感受找需要词（休息/尊重/秩序） |

| 五 | 对孩子哭闹只命名感受+抱，不讲道理 |
| 六 | 一次强制界限后补NVC修复句 |
| 日 | 把最常说的一句豺狼话写成长颈鹿四步 |

# 九、与其他书衔接

- 《如何说…》：倾听与命名≈NVC感受步。  
- 《正面管教》：和善坚定≈需要+界限并存。  
- 《不管教的勇气》：课题分离帮助分清「谁的需要」。  
- 《家庭的觉醒》：恐惧觉察帮助诚实填写「感受」。

---

# 十、一句话给九个月家长

婴儿听不懂四步演讲，但闻得到你心里是豺狼还是长颈鹿。先把四步用在自己与伴侣身上；对他，用看见与满足需要的手臂说话。

# 扩展实践：四步写纸条（怒火降温）

怒到想吼时，强制写四行再行动：  
观察：________  
感受：________  
需要：________  
请求：________（对谁，具体做什么）  

写完再决定：抱孩子 / 换手 / 离开热源。  
**【现在可用】**：请求对象优先是伴侣或自己，不是婴儿。

# 扩展实践：感受词表（中文简表）

舒适侧：安心、轻松、喜悦、感激、好奇、满足。  
困难侧：难过、害怕、焦虑、疲惫、孤单、委屈、烦躁、无助。  

禁止用「我觉得你……」冒充感受。  
每天给孩子的哭选一个困难侧词说出来。【现在可用】语气版。

# 扩展实践：伴侣NVC十分钟

一人说一个困扰（四步），另一人只反映：「你观察到……你感到……你需要……你希望我……」不辩解。交换。  
**【现在可用】**：夜哭压力是高频主题——练完再进婴儿房，豺狼音量会下降。

**【书中未见】**：精确分钟配方；请按自家节奏微调。

把前面的原则再压进今天：选一个场景，只练一个动作，写一行观察。

1. **场景选择**：喂养、睡眠、换尿布、爬行探索、与客相处、夫妻换手——挑今晚最可能炸的一个。  
2. **动作**：只用书中一种工具（诚实短句 / Yes and / 四步里的观察 / 无条件爱宣言 / 课题分离自问 / ICPS式二选一的萌芽 / 身体放松）。  
3. **记录**：他的反应（哭峰长短、是否靠近、是否再试）；你的身体（肩是否降下来）。  
4. **验证标准**：不是「一次成功」，而是「你是否比上周少用羞辱/威胁/评判」。  
5. **九个月提醒**：语言少、重复多、身体在场大于道理；无效时先查饿困病，再查方法。  
6. **伴侣同步**：用一句话告诉对方你今晚只练什么，避免互相拆台。  
7. **收尾**：睡前三十秒——「今天我守住了____，明天我想改____。」

**【补充例子（非书中）】**：若今晚场景是「洗澡哭」——先连连接（毛巾预暖、你的脸出现在他视野），再办事；把「快点洗完」改成「我们还有肚皮、还有小脚」。

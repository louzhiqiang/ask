# 《陪孩子终身成长》整理笔记

**作者核实**：**樊登**；中国友谊出版公司 2020年4月。提出亲子三根支柱。帆书/得到可读。  

**年龄标签**：【现在可用】/【1–3岁】/【偏3岁以上】

## 核心一句话

养育是复杂体系，靠三根支柱驱动：**无条件的爱、价值感、终身成长心态**——发生在问题出现之前的日常。

# 一、无条件的爱【现在可用】

不是溺爱：接纳人+有边界。反对交换式爱（考好才爱）与威胁式爱（不听话就不要你）。  
**行动**：批评行为后仍明确「我爱你」；禁止抛弃威胁。  
**验证**：孩子敢示弱、敢失败后回家。

# 二、价值感【1–3岁】萌芽；【现在可用】被需要的体验

让孩子参与家庭、被具体肯定「你的帮忙有用」。无人自带价值感。  
**【现在可用】**：他的笑引起你笑=影响力体验。

# 三、终身成长心态【偏3岁以上】话术多；态度【现在可用】起

关注过程与策略，允许失误；固定型心态只想证明自己。  
**【现在可用】**：少贴「真聪明/真笨」；描述努力尝试。

# 四、复杂体系与父母角色

孩子成长非简单因果操控；陪写作业式盯防可能让孩子对付父母情绪。父母学习=神助攻。  

**【补充】**：与《家庭的觉醒》同向——先觉察自己。

# 五、实践表

| 支柱 | 9个月做法 | 1–3岁 | 验证 |
|------|-----------|-------|------|
| 无条件爱 | 禁威胁丢弃；哭有回应 | 行为批评后确认爱 | 敢靠近 |
| 价值感 | 回应其影响 | 小贡献 | 愿帮忙 |
| 成长心态 | 描述尝试 | 过程夸 | 敢再试 |



# 六、一句话

先让爱没有交易，再让他觉得自己有用，再一起把困难当成可练的关卡——九个月从「回应与不威胁」开始就够。

# 扩展：三支柱日常化（续0）

无条件的爱：今天是否把爱绑在「睡得好/不哭」上？价值感：是否让他的行为改变过环境（摇铃你跳舞）？成长心态：摔倒后你说「好险，再试」还是「叫你慢点笨」。复杂体系意味着没有一招永久有效，只能力求支柱不倒。叛逆与对话章偏大龄，婴儿期把「有效对话」缩成命名感受。修复与原生家庭章：你吼完后的修复，也在改写自己的童年剧本——书中有相关章节精神，细节未全录。

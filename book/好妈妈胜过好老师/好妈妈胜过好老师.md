# 《好妈妈胜过好老师》整理笔记（精编·0–3焦点）

**作者核实**：**尹建莉**（中国）；《好妈妈胜过好老师》及实践版等；作家出版社等版次。帆书有樊登与尹建莉相关分享。  
**说明**：原书覆盖面广至学龄；本稿按「对9个月–3岁当下有用」精编约略加长精简版，学龄刷题等从略。

**年龄标签**：【现在可用】/【1–3岁】/【偏3岁以上】

## 核心一句话

好妈妈胜过好老师——早期决定性影响在家庭：安全感、语言与情感交流、信任尊重，远重于提前灌输知识与严控。

# 一、早期教育是什么【现在可用】

公开笔记/章节方向：0–3重在感官、语言互动、好奇心与安全感，不是认字竞赛。多说话、唱歌、触摸、游戏；保护专注与想象。  

**行动**：地板时光；叙述日常；少屏。验证：对视与咿呀回合是否增加（叠《父母的语言》）。

# 二、爱是信任与尊重，不是物质堆叠

尹建莉强调真正的爱含信任尊重；打骂与奖惩说教皆非上策。  

**【现在可用】**：回应需求≠无边界满足一切购物欲（婴儿期少物质战，多陪伴）。  
**【1–3岁】**：规则清晰+尊重人格。

# 三、学习品质先于抢跑【偏3岁以上】书中大量；幼儿萌芽【1–3岁】

保护内驱与阅读兴趣；有心之举可能毁阅读内驱（公开评论常引）。  
**【现在可用】**：共读是温馨连接，不考试。

# 四、实践表

| 主题 | 做法 | 年龄 | 验证 |
|------|------|------|------|
| 语言环境 | 多说完整句 | 现在 | 咿呀/词汇 |
| 安全感 | 稳定回应 | 现在 | 敢探索 |
| 规矩 | 尊重+清楚界限 | 1–3 | 少羞辱仍停危险 |
| 早教班焦虑 | 家庭互动优先 | 现在–3 | 你是否少焦虑性报班 |

**书中未见**：九个月辅食与睡眠医学细则（非本书重点）。

# 五、一句话

你在家说话、拥抱、信任的方式，就是他的第一所学校。

# 扩展：家庭是第一课堂（续0）

尹建莉强调父母自我修养。九个月少焦虑早教课程，多问：今天有没有一段不被手机打断的相处？有没有把孩子当物品训斥？有没有在信任中给安全探索？品格在细节：你是否守时对孩子的承诺（「妈妈马上回来」真的马上）。学龄章节（作业战争等）留待三年后重读全书。【偏3岁以上】内容从略但原则已在：尊重、信任、少羞辱、保护兴趣。

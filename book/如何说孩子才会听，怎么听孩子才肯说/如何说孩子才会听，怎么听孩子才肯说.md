# 《如何说孩子才会听，怎么听孩子才肯说》整理笔记

**作者核实**：[美] **阿黛尔·法伯（Adele Faber）**、**伊莱恩·玛兹丽施（Elaine Mazlish）**；英文 *How to Talk So Kids Will Listen & Listen So Kids Will Talk*；中文中央编译出版社等版次。帆书有樊登解读。  
**读者**：9个月，准备0–3。对话技巧偏会说话孩子；婴儿版需砍短。据樊登解读与公开笔记。

**年龄标签**：【现在可用 9月–1岁】/【1–3岁】/【偏3岁以上】

## 核心一句话

孩子有好感受才易有好行为。先**接纳感受**（感受无对错，行为可限制），再谈合作、代替惩罚、自立与描述式赞赏。

# 一、帮助孩子面对感受（四招）

1. 全神贯注倾听  
2. 「嗯、哦、这样啊」简单回应  
3. 说出感受（「你很难过」）  
4. 用幻想满足愿望（「真希望立刻变出蛋糕」）而非纯讲理  

**反例（书）**：忽略（「有什么了不起」）、否定饿疼、急着给建议。  

**【现在可用】**：代说感受+抱；幻想可简化为共情语气。  
**【1–3岁】**：四招逐渐完整。  
**【偏3岁以上】**：长对话与角色互换练习。

**场景（樊登转述）**：兔子耳朵断了——不说「再买一个没关系」，而说「断了真可惜，你很难过」。  
**验证**：孩子是否更愿继续说；情绪是否下降。

# 二、寻求合作五法

描述问题；给信息；一个词；说自己感受；写便条。  
少责备命令威胁讽刺。  

**【现在可用】**：描述+一个词（「烫！」）+移开。  
**【1–3岁】**：加「妈妈很着急，我们要出门了」。  
**【偏3岁以上】**：便条好玩有效。

**验证**：少对抗、多行动。

# 三、代替惩罚七法（公开笔记）

请孩子帮忙；强烈不同意但不攻人格；阐明期望；指出弥补；提供选择；采取行动；体验相关后果。  

屡教不改五步：谈感受需求→说你的→一起想办法→写下→挑选执行。【偏3岁以上】  
**【1–3岁】**缩为命名+界限+选择+行动。  
**【现在可用】**：行动=抱离危险；无「面壁」。

# 四、鼓励自立六法

选择机会；尊重努力；少盘问；不急着给答案；鼓励外部资源；不扼杀希望。  
**【现在可用】**：少代劳抓握与探索（叠自然法则）。  
**【1–3岁】**：自己舀饭尝试，你忍住接手。

# 五、赞赏三法

描述看见的；描述你的感受；总结为一个词（「这叫有条理」）。  
避免空泛「你真棒」造成压力或依赖评价。  
**【现在可用】**：纯描述。

# 六、从固定角色解放【偏3岁以上】为主

别当众贴「害羞、捣乱」标签；给新形象机会；让他听见你的正面评价。  
**【1–3岁】**开始小心不当面议论。  
**【现在可用】**：少在客人前议论「他就爱哭」。

# 七、实践表（9个月–3岁）

| 场景 | 怎么说/做 | 年龄 | 验证 |
|------|-----------|------|------|
| 玩具坏了哭 | 说出难过+陪伴 | 现在–3 | 愿靠近 |
| 要蛋糕没有 | 共情+幻想+替代选项 | 1–3 | 软化 |
| 不穿衣 | 描述+一词+选择 | 1–3 | 合作↑ |
| 打人 | 不同意+期望+弥补/替代 | 1–3 | 频率↓ |
| 自己做事 | 不抢着做；描述努力 | 现在–3 | 坚持试 |
| 赞一次收拾 | 描述看见+感受+词 | 1–3 | 愿再试 |

**诚实**：大量话术假设语言理解；九个月=情感命名+身体界限+少否定感受。

# 八、一句话

先让他觉得「我的难受有人懂」，再谈规矩；懂了感受的孩子，更听得进你后面那句「但是不可以」。

# 扩展：感受无对错，行为有界限（续0）

法伯与玛兹丽施最容易被误读成「只共情不设限」。原书明确：所有感受可接纳，某些行为必须限制。九个月版：允许大哭表达难受，同时按住要打脸的手。

**四招拆开练**：第一周只练倾听与「嗯」；第二周加感受词；第三周尝试一句幻想。「我知道你想要手机，真希望它变成牙胶。」然后给牙胶。验证：抢手机冲突是否缩短。

**合作五法婴儿版**：描述「尿布脏了」；信息「我们换干净的」；一词「换！」；感受「妈妈手冷，动作快点」；便条不适用。学步儿可用贴纸箭头当「便条」。

**代替惩罚**：采取行动=抱离；弥补=一起轻轻摸摸被打到的人（示范）；选择=「走还是抱着走」。不要关小黑屋。

**赞赏**：描述「你爬过来了」比「你好棒」更安全——少制造表演型人格。叠父母的语言。

**常见失败**：共情后立刻「但是你要……」说教——孩子会觉得共情是陷阱。先停顿，等情绪下降再界限。

**书中漫画练习**：公开笔记多提有漫画，具体格未转录——标书中未见逐格。父母需自己对着章节练习说话，才能内化。

# 九、与情感引导、正面管教叠用

《你就是孩子最好的玩具》的「反应情感」≈本书说出感受；正面管教的连接≈倾听在场；本书合作五法与代替惩罚七法提供更多话术零件。九个月只取零件：在场、命名、界限、替代。

**练习作业（补充结构）**：选一个高频冲突（换尿布），连续五天只用「嗯+感受词+短界限」，录音自己语气，看是否少否定句。

# 十、换尿布 / 出门 / 抢手机：逐字示例（公开原则+年龄改写）

**换尿布反抗**【现在可用】：「哦，你不想躺着（感受）。腿要抬一下（信息）。抬！（一词）。妈妈轻一点。」不说「再不躺就不管你」。  

**出门拖拉**【1–3岁】：描述「鞋子还在地板」；感受「妈妈怕迟到心里紧」；选择「自己穿还是坐着穿」。  

**抢手机**【现在–3岁】：幻想「真希望手机变成饼干」+界限「手机不是牙胶」+替代。验证：冲突轮次是否减少。

书中原例多为学龄前对话，此处为原则迁移；非原文逐字，已按规则改写并标注年龄。

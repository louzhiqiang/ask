# 《不吼不叫》整理笔记
## 如何平静地让孩子与父母合作

**作者核实**：[美] **罗娜·雷纳（Rona Renner）**；译者钟煜；上海社会科学院出版社 2016；ISBN 9787552010817。副标题：如何平静地让孩子与父母合作。樊登读书会有分享。  
**方法关键词**：ABCDE、4C、气质九维度。据公开笔记/豆瓣批注，无盗版全文。

**年龄标签**：【现在可用 9月–1岁】/【1–3岁】/【偏3岁以上】

---

## 核心一句话

吼叫常因大人失控，解决不了合作还伤害关系。被激怒用 **ABCDE** 先稳自己；日常用 **4C**（沟通、选择、结果、连接）；吼过后真诚道歉并补救。危险时可大声警示，事后不再羞辱加码。

---

# 一、吼叫是什么；危害

笔记：吼叫时怒气与挫败上升，呼吸心跳变，思维不清。目的常是泄愤与威胁。  
**慎重坚定的语气**可以传达界限，不等于吼。  
长期吼叫：扭曲自我与世界感受；易学攻击性冲突；青春期阴影（笔记方向）。

**【现在可用】**：婴儿听不懂讲理，但听得懂怒气——你的神经系统在训练他的安全感。

---

# 二、ABCDE【现在可用】——用在父母身上

| | 含义 | 九个月例子 |
|--|------|------------|
| A Ask | 自问感受与负面想法 | 「我是不是没睡够？」 |
| B Breath | 慢呼吸3–5次 | 先吸够再抱 |
| C Calm | 现实想法替升级想法 | 「9个月会抓是探索」 |
| D Decide | 年龄气质与需要 | 出牙？过刺激？ |
| E Empathize | 同理并说出 | 「好难受，我在」 |

顺序可调。验证：吼的次数、事后羞愧是否下降。

**笔记场景方向**：孩子哭闹引发对他人的指责升级→改用呼吸+拥抱同理后情绪落下来。

---

# 三、4C【1–3岁】；婴儿简化

1. **沟通**：短、具体、可示范。「沙子不进嘴」＞「听话」。【现在可用】一词+手势  
2. **选择**：真实二选一；没得选别假问。【1–3岁】；婴儿举两物  
3. **结果**：规则与相关结果；婴儿阶段=安全移开与惯例，非复杂惩罚戏。【现在可用】  
4. **连接**：一对一时间，少说教，玩与听。【现在可用】每天一小段眼神游戏

**验证**：有连接后是否更好带；具体指令是否比抽象形容词更有效。

---

# 四、气质九维度【现在可用】观察

活动量、节律、接近/回避、适应性、敏感度、反应强度、情绪本质、注意分散、坚持度。  
调整你的期待与节奏去「合拍」，而非只要求孩子改。

**【补充例子（非书中）】**：高反应强度婴儿哭声大——不是「脾气坏」，先降刺激。

---

# 五、已吼叫 / 他人吼叫

**道歉三件套**：后悔情绪 + 自己的责任 + 补救。示范道歉。【全程】  
**他人吼**：孩子不在场沟通；感谢帮忙；一起想办法；无意改变则调整看护（笔记）。

**替代吼叫的工具（笔记）**：日历表格、放低音量、幽默、数数、静静看着、再给一次表达机会、拉孩子想办法。【1–3岁】/【偏3岁以上】较多；婴儿用仪式与环境设计。

# 七、一句话

世界的和平始于家庭（笔记金句方向）——九个月你练的不是「零怒气」，而是**怒气来时还有选择**：呼吸、读需要、坚定短句、连接。

# 八、追踪吼叫：记录表（笔记方法）【现在可用】用于大人

事件→你的反应→你的回应→后续→气质因素→评估。  
连续记一周：你会发现触发器常是睡眠不足、时间压力、完美期待，而不只是「孩子坏」。

**【补充例子（非书中）】**：九个月晚八点哭，对照记录若多在你加班日爆发——先改自己作息与分工。

---

# 九、外部与内部触发器

**外部**：哭闹、拖拉、拒绝、公开场合难堪。  
**内部**：羞耻、孤立无援、健康、原生家庭模式、「踢猫效应」。  
笔记强调：先看见自己，才改得了吼。自我同情≠放任吼叫，而是承认错了并找路径。

---

# 十、7不吼之类提醒（分享记录方向）

吃饭睡觉场景尤其避免吼——关联生存与安全感。危险警示后若再吼责备，后一段不必要。

**【现在可用】**：喂奶/睡觉被打断时，优先换人支援，而非对婴儿发泄。

# 十一、4C 展开例子

**沟通**：把「你怎么又不听话」改成「鞋子穿上，我们出门」。  
**选择**：「现在穿还是五分钟沙漏响了穿」——真选择；「穿不穿随便」若实际必须穿则是假选择，破坏信任。【1–3岁】  
**结果**：相关、尊重、合理——不是报复性没收一切。婴儿阶段结果=自然安全结果（碰热水被你拉开）。  
**连接**：每天10–20分钟手机远离的地板时间。【现在可用】

---

# 十二、实践深化表

| 触发 | ABCDE要点 | 4C要点 | 年龄 |
|------|-----------|--------|------|
| 尿布反抗 | C：他不是针对我 | 沟通短+事后连接游戏 | 现在 |
| 学步摔东西 | D：探索还是累 | 结果=一起捡；选择先捡谁 | 1–2 |
| 公共哭闹 | B呼吸后带离 | 连接+坚定离开 | 1–3 |
| 老人吼孩子 | 事后沟通 | 保护连接；统一话术 | 全程 |

# 十三、一句话加厚

不吼不叫不是当木头人，而是把能量从「震慑」转成「清楚+连接」。九个月你的平静神经系统，就是他正在下载的操作系统。

# 扩展：把吼叫变成数据（续0）

罗娜·雷纳的路径不是道德羞辱父母，而是觉察—替代—修复。九个月阶段，吼叫往往冲着「哭不停」——而这恰恰最需要你的皮层上班。把每一次几乎要吼的瞬间当成数据点：几点、睡够没、是否饥饿、是否客人在场的羞耻感。

**ABCDE 微练习**：只练 B 和 C 三天——只要想提高音量就先三次呼吸并改口「他很小」。再练 E：强制说一句感受命名。验证：音量峰值是否下降。

**4C 与九个月**：沟通=两个字；选择=举两物；结果=移开；连接=地板十分钟。不要对婴儿做复杂「自然后果讲座」。

**气质合拍例**：节律性低的婴儿作息飘→你降低「必须准时」的自我攻击，改用窗口而非整点，吼会少。敏感度高→减访客噪音。书中九维是观察透镜，不是病名。

**道歉示范加长**：「妈妈刚才声音很大，吓到你了，对不起。妈妈累了，但那不是你的错。我们抱抱，等一下妈妈喝口水再陪你。」婴儿听不懂每个字，听得懂修复。

**伴侣分工**：约定「崩溃时换手暗号」，避免两人同时升级。书中强调连接，双父母连接也算。

**公共场合**：先带离（保护双方尊严），再 ABCDE，再短坚定句。围观羞耻是内部触发器——点名看见它。

**世界的和平始于家庭**：不是鸡汤，是提醒——你今天下载进孩子身体的，是协商还是战争模式。

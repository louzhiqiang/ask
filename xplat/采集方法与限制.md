## 1. 样本设计

- X近期窗口：Orange为2026-10-28 07:24至11-09 07:02（UTC+8）；Dan为2026-07-29 07:28至11-09 00:15（UTC+8）。更新频率差异大，不能把两人样本当相同天数，也不能拿绝对点赞比较平台/语言优劣。

## 2. 工具路径

X只用 `x` MCP公共读：用户批量查询、用户发帖列表、历史公开帖搜索；先读x-api-mcp-guide。没有调用X底层API或读取登录凭证。

YouTube主清单命令：

```bash
yt-dlp --flat-playlist -J 'https://www.youtube.com/channel/频道ID/videos'
```

分层抽样脚本：`fetch_samples.py`。公开字幕/自动字幕命令核心：

```bash
yt-dlp --skip-download --write-info-json --write-subs --write-auto-subs \
 --sub-langs 'zh,zh-Hans,zh-Hant,zh-CN,zh-TW,en' --sub-format json3 URL
```

ASR只针对成功公开读取的无字幕视频，不用于绕过验证：

```bash
yt-dlp -f 'bestaudio/best' --download-sections '*0-360' URL
/workspace/xhs/.venv-funasr/bin/python /workspace/xhs/transcribe.py --threads 4 FILE
```

一轮只运行一个FunASR进程；先处理两段，结束后再处理第三段。TXT/SRT保留原识别错误；引用优先采用清晰句，数字、职务、专名识别不清的句子不作为事实。没有人工逐句听校，不宣称字幕级准确。

## 3. 失败究竟是什么，怎么处理

### YouTube不是整站失败，是单视频访问/字幕失败

1. 若视频返回 `Sign in to confirm you’re not a bot`，停止该视频正文获取，不登录、不导入cookies、不换客户端绕过；仅保留已成功清单中的标题/观看数，日期缺失就写缺失。
2. 多个大人學样本的原中文`zh`已下载，但后续请求翻译字幕`zh-Hans`/`zh-Hant`时返回 **HTTP 429**，导致同一调用没走到写详情JSON。保留已成功的原中文，不重试翻译端点。对这些已公开解析成功的页面，另做不请求字幕的元数据保存；若随后出现机器人验证，也停止，不再重试。
3. 李自然说的16个成功详情返回字幕/自动字幕均空，日志为 `There are no subtitles for the requested languages`。只对成功公开下载音频的3条做0—6分钟ASR，没尝试转写被验证拦下的条目。
4. 工具提示未安装支持的JavaScript runtime；清单与部分公开详情仍成功。没有安装登录辅助、抓取cookie或改用内部接口。警告意味着可能缺某些视频格式，不能将失败解释为视频不存在。
5. 完整逐项错误见 `source_errors.md`。原始日志在 `youtube_daren/samples/`、`youtube_liziran/samples/`；采样证据索引同时列出初始错误。

### X限制

- 请求100条实际返回25条，因此真实近期基线仅各50条作者发布样本，不写成各100条。
- 排除回复参数未严格执行；另按referenced_tweets与in_reply_to_user_id计算剔除回复的敏感性：Orange45条主帖，均赞141.51、中位74；Dan46条主帖，均赞9800.98、中位9437。低互动产品续帖的分发位置与内容用途混杂，不能单因归结为卖产品。
- 有些长帖只返回截断text或短链接/文章标题，虽有互动计数，未获得文章正文。它们可计入时间线均值，不能按标题想象内容；最高条目正文缺失时在拆解中明确标注。
- 两次“高互动”搜索试探返回了低于筛选阈值的结果；未将该返回集当作真正的Top榜，也未混入平均值。热门对照从实际50条指标排序，完整统计只来自保存的时间线数据。
- 2022历史搜索只是年末断面，不是整年随机样本/连续增长曲线。
- 同一条在数次读取时计数可能变化。均值使用 `orange_50.json` / `dan_50.json` 保存的去重快照，引用当次原文补全不重写基线。

## 4. 数字与引用规则

- X点赞、转发、回复、收藏、曝光均取公开public_metrics；曝光不是独立人数。按返回原样保留，不估算缺失指标。
- YouTube全量均值、中位数、Top10占比、近期10条均值均用 `--flat-playlist` 清单。该页面计数可能取整，如673000；详情673254只放证据索引，不混入全量基线制造假精度。
- 发布精确timestamp转换UTC+8；若只返回upload_date日历字段，标注“平台日期字段、时区未提供”，不捏造时刻。找不到日期的只作缺失记录。
- 原作者商业/科技/心理断言仅用来分析表达方式，不视为已验证事实。ASR/作者字幕也不是事实正确性的保证。
- “主轴、模板、共性、为何有效”是分析者归纳，不是声称采访过作者/读者或掌握推荐算法。
- 无评论系统采集；不做粉丝画像和读者动机的确定判断。
- YouTube长视频与新视频曝光时间不等；没有首周观看、曝光、点击率、留存、收入等数据。“倍均值”只描述快照差异，不说明因果。
- 四位是目的性选择，不足以比较平台题材整体胜率；也没全平台搜索确定“最像”排名。

## 脚本模板 1｜干货清单「我踩过的坑 → N 条方法 → 一句价值观」（3–5 分钟）

1. 场景开头（10 秒）：一个粉丝或朋友的遭遇加一个数字。参考 #185「公司只给他一个月的赔偿」。
2. 立身份（10 秒）：「作为一个刚刚经历过裁员的九八五毕业生」（#185）。
3. 「首先 / 第一 / 第二 / 第三」，每条配一个具体动作（#185「把手机调成飞行模式，然后打开录音」）。
4. 升华（20 秒）：把方法上升到人生选择。参考 #185「绝对不在那几平米的工位上」。
5. 收尾：「拜拜」或「希望这 N 条 X 能帮到正在迷茫的你」（#132）。

## 脚本模板 2｜个人故事 → 女性议题（2–4 分钟）

1. 童年或亲密关系里的一句刺痛的话（#104「嗨都不漂亮」；#2「他是姐妹吧」）。
2. 两到三段时间线：小时候 → 大学 → 现在。
3. 转折：遇到的人或书改变了看法（#2「和鱼在一起的这八年……」）。
4. 拉到群体：「越来越多的女性……」（#2）。
5. 金句收尾，邀请评论（#104「我更希望你们在评论区留下这句话」）。

## 脚本模板 3｜采访 / 他人视角（3–5 分钟）

1. 问题句开头，直接放受访者原声（#1「现在很多年轻人都想结婚，不愿意生孩子，对这个怎么看？」）。
2. 两到三位受访者的回答，各有反差。
3. 自己的一段总结（#1「如今房子、婚姻、生育都不再是避须（必须）秀（项）」）。
4. 变体：采访一位高收入人物，提炼「他们哪里不一样」（#90）。

## 脚本模板 4｜年度复盘 / 跨年号召（每年 11–12 月）

1. 「二零 XX 年是我……最颠覆的一年」（#113）。
2. 三到五条今年的认知或做过的事（#57「今年做过最害怕的一件事儿……」）。
3. 用一两个朋友案例佐证（#116 #165）。
4. 指向下一年：「二零二四年，行动起来吧，朋友们」（#165）。

## 图文模板 5｜短行随笔（A 期，适合图文）

1. 首行放别人的一句话（#313 #288）。
2. 用「-」分段，每段一到三行，还原对话。
3. 中段写自己的反应和理由。
4. 末段一句道理（#301「免费的，往往是最贵的」）。
5. 固定签名：「👧我是琳达不呆，……」「🌟点击我的头像，看更多干货笔记」（#462）。

## 30 秒口播填空（万能瘦身版）

「（某人）跟我说『______』。作为一个（身份）的人，我想说：首先______，其次______，最后______。其实______才是真正的自由。拜拜。」

## 固定开头和结尾

- 开头：「今天教你们……」（#154）、「今天手把手教……」（#58）、「决定做一个专辑……今天是第一期」（#215 #226）。
- 结尾：「……拜拜。」（39 条视频）；跨年时用「二零 XX 年，行动起来吧，朋友们」。

## 使用注意（防踩坑）

- 收益数字（「七位数」「卖了九千多」）必须是真实的，否则会伤信任。
- 女性议题要用自己的真实经历撑住，只讲观点容易被吵起来。
- 2023–2024 的「搞钱 / 做小红书」话术已经泛滥，2025 年作者自己也把签名改成了「长期主义」（#113）。

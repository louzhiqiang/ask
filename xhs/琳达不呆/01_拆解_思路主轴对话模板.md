## 一、思路构建：「一个具体场景 / 一句扎心的话 → 我的经历 → 第一第二第三 → 一句金句收」

### 1.1 典型推演链

1. **场景或冲突句开场**：别人说的一句话、一个数字、一次裁员。
2. **立身份**：交大、程序员、被裁、做自媒体、年入七位数。
3. **分点给方法**：「首先 / 第一 / 第二」。
4. **价值观升华**：自由、行动、长期主义、女性的可能性。
5. **口语化收尾**：「拜拜」或一句金句。

例：#185《拿去！你永远不知道哪一刻公司会突然裁员…》

- 场景：「裁员前前的粉丝群里有有一粉粉丝突然被裁员了……公司只给他一个月的赔偿」
- 身份：「作为一个刚刚经历过裁员的九八五毕业生」
- 方法：「九点通知大家开会，九点十五通知裁员……把手机调成飞行模式，然后打开录音」
- 升华：「我们永远不会获得比安全感更高级的快乐。这种快乐在山野间……但是绝对不在那几平米的工位上。」

例：#154《这样把焦虑写下来后，命运齿轮真的转动了！》

- 开场：「今天教你们一个五分钟彻底解决焦虑的办法。这个办法我从大学开始用用了，已经快十年了。」
- 原理：「我们的大脑很喜欢夸张，本来只是一个小小的a问题……」
- 方法：「我会给出三个实操的方法，以及到底应该怎么写。」
- 收：「十年前的我一焦虑就想回避，现在我反而会去分析它，去拆解它，去直面它。」

### 1.2 论证方式

- **自己的经历是主证据**：#106「我二十多岁最好的决定就是没有在我最困难的时候和他结婚……那时候我二十三岁，刚上班就遇到公司大规模裁员」。
- **朋友的案例加具体数字**：#116「比如我朋友雪莉两万多粉丝，今年赚了六十多万，乐乐三万粉丝，一个商单六千五块」；#143「我朋友用我的方法，一天笔记卖货十万」。
- **借行业身份说话**：#119「我之前是写推荐算法代码，这个模型征征（整整）有有上万位维……」；#226「碰巧呢我做算法工程师，这四年也写过很多数据分析的代码」。
- **书和名言做背书**：#193「第一小狗钱钱……第二，人类简史」；#171 结尾引《金刚经》「一切有违法（有为法），皆梦幻泡影」。

### 1.3 开头钩子类型

| 类型 | 例 |
|---|---|
| 别人的一句话 / 对话 | #301 标题「她骂我：『你不该住1000块一晚的酒店，太铺张』」；#313「男友打电话说：『你每天都好忙，都没时间陪我了。』」 |

| 紧迫感 | #185「这篇视频你刷到一定要赶紧看完收藏，很可能马上就看不了了。」 |
| 反常识 | #119「真的就是有没有限流这回事儿，没有限流这回事儿。」 |

### 1.4 结尾类型

- **「拜拜」**：39 条视频文字稿出现，如 #113「希望二零二五年我们都能把目光重新回归到自己身上，拜拜。」；#47「我们本来就有让自己舒服的自由，拜拜。」

## 二、主轴：贯穿账号的核心命题

### 2.1 一句话主轴

**「普通家庭的女孩，可以靠认知、行动和信息差，拿回对自己人生的选择权。」**

三层内容都在服务它：

- 认知：读书、复盘、写日记（#370 #450 #193 #75）。
- 行动和钱：职场、副业、自媒体、投资（#185 #116 #143 #58）。
- 女性的自由：不结婚、不漂亮、不穿 bra、选择有「女性气质」的伴侣（#106 #104 #47 #2）。

原句：

- #113「我们从来没有讨论过不做一件事儿给我们带来的风险……你失去了改变自己生活的可能性。」
- #58「我是强烈建议每个人，尤其是女生尽早的去学习股市和投资。」
- #226「只有越来越多的女孩加入到这个行业，我们才能见到越来越多敢于挑战的女性」。

### 2.2 人设与价值观层

- **学霸 + 程序媛**：「交大」在 23 条视频稿、155 条图文正文里出现。
- **被裁员后的自由职业者**：「裁员」出现在 24 条视频稿里（#12 #19 #25 #28 #56 #74 #75 #86 等）。
- **有长期伴侣「鱼」的女性主义者**：#2「和鱼在一起的这八年，他从来不会因为个人喜好向我提出任何要求」；#5「我分享过不少和鱼的恋爱故事」。
- **长期主义**：#113「前段时间我把我自己小红书的签名，一个人一年赚到七位数改成了长期主义，是最浪漫的事。」

## 三、对话特点

### 3.1 语气

像熟悉的学姐、闺蜜：温和、真诚，常有自嘲，讲到价值观时会变得坚定。

- 自嘲：#57「我唱歌有多抽象了，就是有次我歌瘾来了……结果没唱两首我就把自己唱跑了。」
- 坚定：#104「每一个女孩都有不美的自由」。

### 3.2 人称与对话对象

- 第一人称叙事为主，「我」带出几乎所有观点。
- 对象是「姐妹们 / 女生」：「姐妹」出现在 36 条视频稿和 13 条图文里；#75「希望每个看到这里的姐妹们……开启自己真正想要的生活，拜拜。」
- 对象也包括「普通家庭孩子 / 大学生」：「普通家庭」出现在 19 条视频稿里（#61 #81 #116 #134 #136 等）。

### 3.3 口头禅与句式

- 「真的」：173/223 条视频稿出现；「其实」157 条；「所以」165 条；「首先 / 第一」158 条。
- 「今天教你们 / 手把手教」：#154「今天教你们一个五分钟……」、#58「今天手把手教小白，挑选自己的第一只股票」。
- 「信息差」「搞钱」「搞脑」：#167「普通人能否赚到钱，拼的根本不是天赋和智商，而是信息差」；#193「搞钱先搞脑，搞脑先读书」。

### 3.4 图文笔记的写法（和视频不同）

- 短行分段，用「-」或「.」隔开，节奏像诗（#370 #301 #288）。
- 对话体叙事：#313 整篇几乎是对男友说的话：「宝贝你看，我每天要工作、要看书、要跑步，它们对我都很重要。」
- emoji 做小标题：#480「🍃这3本书改变了我的青春」；#407「❶戴锦华（北大教授）」。
- 结尾加签名和 @校园薯 / 知识薯（#462）。

### 3.5 金句特征

短句对仗，适合截图：

- #370（图文）「刷短视频、某音，是娱乐，不是放松」。
- #301（图文）「“免费的，往往是最贵的”」。
- #165「搞钱的核心，不是钱，是搞不是想，是做」。
- #113「迷茫的时候一定要选择更难走的那条路。」

## 四、是否有模板

### 判断：**有，属于中强模板。** 每个阶段有一套主力结构，但文本不像强签名博主那样逐字固定；最稳定的元素是「个人经历开头 + 分点 + 金句或『拜拜』收尾」。图文时代有逐字固定的签名（157 条）。

### 模板 A｜干货清单：「我（身份）+ 第一第二第三 + 升华」（B、C 期主力）

#226 #185 #193 #154 #116 #132 #58。例：#132「我们总结了十条学校从来没有教过的职场真相」→ 逐条 → 「希望这十条职场真相能帮到正在迷茫的你」。

### 模板 B｜个人故事 → 女性议题（D、E 期主力）

#104 #106 #2 #47 #69。例：#47「不穿bra……聊聊我的感受吧」→ 泰国旅行的经历 → 「对于bra绑定了一个世纪的女性来说，后者才是真正的自由」→「三八妇女节……拜拜」。

### 模板 C｜采访 / 他人视角（D、E 期低频爆款）

#1（上海老人街采）、#90（「我采访了朋友圈里最年轻的亿万富翁」）、#28（第三人称介绍自己）。

### 模板 D｜年度复盘 / 跨年号召（每年 11–12 月）

#171（2023-11）、#165（2023-12）、#113 #116（2024-12）、#57（2025-12）。共同点：结尾都指向下一年，如 #57「二零二六年到了」。

### 模板 E｜图文随笔：「一句对话 → 短行叙事 → 道理」（A 期）

#301 #288 #313 #307 #371，加固定签名。

## 六、可借鉴与不可复制

### 可借鉴

- 用一个具体对话或场景开头，比直接抛观点效果好（#301 #313 #104）。
- 每年 11–12 月做一条复盘或跨年号召（#171 #113 #57）。
- 干货内容配一个价值观收尾，让方法类视频也能被转发（#185 #226）。
- 开系列时明确说「专辑 / 第一期」（#215 #226 #171）。

### 不可复制（或很难复制）

- 交大硕士 + 算法工程师 + 被裁 + 自媒体年入七位数这一组履历。
- 八年的伴侣「鱼」作为长期叙事角色（#2 #5 #69）。
- 五年以上的图文积累和百万粉丝带来的基础流量。

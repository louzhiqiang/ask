## 脚本模板 1｜实战复盘「我的屎山」（3–6 分钟）

**适用**：AI 编程、工具使用、工作流踩坑；要收藏和转发给小白。
**结构占比**：戳痛 10% → 概念人话化 25% → 自证 20% → N 件套 35% → 原则 + 导流 10%。

```
【戳痛】Ok朋友们，你们有没有见过____？（没见过说明你还没见过世面）
【戳误解】很多人以为问题是____，其实本质不是____，而是____。
【人话化】用大白话解释 2–3 个概念：X 就像____（做菜、盒饭、缰绳、电路板通电）。
【自证】给你们看我自己的项目：第___条 commit / 这张截图——我犯了两个非常严重的问题。
【N件套】第一个____；第二个____；第三个____（附一句可以直接丢给 AI 的 prompt）。我说三遍：____。
【原则】核心说白了就是一句话：____。
【开坑+导流】下期讲____，想听的评论区留言；欢迎进群聊 / 订阅周刊，点赞收藏关注，拜拜。
```

**原作示例 #30（1272 赞）**
「有没有见过跑一百二十分钟的CI？」→「代码呢它是你的菜谱……镜像呢就是把这道菜打包成盒饭。部署呢其实就是把你这个盒饭放在服务器上面去卖」→「我犯了两个非常严重的问题……无差别全量测试……没有路径的过滤」→ 写进宪法文件的三条 + CI 15 分钟红线 + 镜像保留策略 →「lessons more（less is more）」→「点赞收藏关注我们，下期再见」。

同结构：#36（开工四件套）、#2（harness 四层）、#28（五条命令体检）、#7（三种测试）。

## 脚本模板 2｜热点速读「一条视频讲清楚 N 件事」（3–8 分钟）

**适用**：新模型、新论文、新开源项目、跑分；适合做付费周刊的免费预告。
**结构占比**：热点 10% → 学习目标 5% → 背景 20% → 逐点拆解 50% → 对你的意义 10% → 导流 5%。

```
【热点】最近____大火 / ____又整新活了，网上都在说____。
【目标】今天我要让你一条视频明白三件事：①____ ②____ ③____。
【背景】先讲一下____是什么（用一个比方：驾驶舱、底盘、裸露的主板）。
【逐点】第一个____（配一个小算术或小场景，比如 2×3 做三次 attempt）；第二个____；第三个____。
【意义】这跟我们平时用 AI 写代码、做产品有什么关系？____。
【预告+导流】这期太长分两期，下期讲____；更多解读在我的周刊，私信订阅；点赞收藏关注，拜拜。
```

**原作示例 #26（868 赞）**
「我真的已经很久没有这么兴奋了……我要让你一条视频，明白三件事情」→「clock code cotex这些它更像是一个已经组装好的整机……DC carneness（DeepSeek harness）……更像是一个裸露的主板」→ 用 VS Code 插件类比「everything is the plugin」→ 适合什么人 → 周刊和群聊导流。

同结构：#3（RL 难点，分两期）、#10（Jev 模型）、#4（Harness²）、#14（GPT6 benchmark）。

## 脚本模板 3｜创业陪跑：真实案例 → 思维纠偏 → 问题清单（2–5 分钟）

**适用**：GTM、市场调研、找用户、定价、上 Product Hunt；吸引在做项目的人。
**结构占比**：案例 30% → 诊断 25% → 公式或问题清单 35% → 系列预告与招募 10%。

```
【来源】今天刚好看到评论区 / 群里有小伙伴问：____。
【案例】他做了____，上线后____个用户，其中熟人____，付费转化率____。
【诊断】说难听一点，你卡住的不是____，是你还没从____（developer）转换成____（founder）。
【公式】你的客户为什么给你钱？价值 > 他要付出的成本。问问题就是问出公式里所有的变量。
【清单】①你上一次遇到这个问题是什么时候？②当时怎么处理，花了多少时间和钱？③现在的替代方案最让你受不了的是什么？④换成你的产品要付出什么代价？
【明天就做】翻通讯录找到一个够得着的人，约 50 分钟电话；再让他推荐下一个。
【预告+招募】这个案例会一直更到结果揭晓；你有项目想做调研，私信我，我们一起做 case study。
```

**原作示例 #43（2240 赞，全号最高）**
「调研的目的是在你真正投入大量的真金白银，还有时间之前就以最小的成本去回答这个事情值不值得做」→「我知道你很急，但是你先别急……第一步不要去做宏观分析……我讲三遍啊」→「我的咨询师朋友在抱怨，现在EMR太难用了……我就直接翻通讯录」→「只要能找到一个的话，你就能找一串」→ 群聊导流。

同结构：#39（30 个用户、付费转化为零的案例）、#42（四类提问）、#37（先别急着上 Product Hunt）；图文版 #40 #45。

## 使用注意（防踩坑）

1. **模板 1 的命门是「自证」**。没有自己的 commit、截图或数据，就只是转述教程，可信度会掉一大截。
2. **模板 2 要讲「对你意味着什么」**，不然就是新闻搬运。她近期这类片子赞不高（#3 只有 36 赞），注意别只做这一种。
3. **模板 3 的案例要征得当事人同意**。她在 #40 写明「感谢这位小伙伴愿意让我把这段经历分享出来」。
4. **中英夹杂要真实**。她的混说来自 15 岁出国（#50）；硬凹英文会显得装，用自己的口语习惯就行。
5. **毒舌要配真诚**。「你给我出去」（#42）能成立，是因为她同样狠狠自嘲（#52「so fuccking embarrass」），只毒舌不自嘲容易招黑。

## 文字稿

刚才发生了一件让我特别难受的事情，不吐不快。我自己运营了一个两千三百人的AI付费社群和课程。今天呢一个粉丝加到我说大圣我想跟你学AI.然后我看到你的介绍说，你讲的是AI底层逻辑。但是我想学实战，我就问他说你想学习什么类型的实战呢？他说我想学习AI自动化，然后我就问了他一个问题，我说是自媒体上铺天盖地宣传的那种一键自动化的案例吗？

啊，他没有正面回答我的问题，然后他给我介绍一下他的背景。他说他是一个职场工司，他想要去做艺人公司，他脑子有很多的想法。然后他想要用AI去提效去帮他去验证。他觉得自己作为职场的牛马，没有那么多的时间去试错，所以他会对AI自动化这件事儿非常感兴趣。后来我就回复了，他说我说艺人公司不是这么做的，艺人公司本质是创业，创业不可能靠一键自动化这样的东西去帮你搞定。

当然后来这个粉丝就没有再回复我了，可能是我说的话太重了。我这里先声明一下，我发这个视频并不是要吐槽我这个粉丝。相反，我想用这样的方式去跟他对话，说一下我内心的想法。因为AI学习和艺人公司这两件事儿正好命中了我的术公人，我应该是非常发言权的。我们先来聊一下AI的学习。呃，现在的整个自媒体圈，关于AI学习有两个非常极端的观点。

第一个就是什么呢？Ai不用学，因为嗯AI不就是这种自然语言表达你的诉求嘛，然后像cloud code collects就能满足你的诉求，这是第一个极端的观点。第二个观点是AI非常难学。因为他会看到市面上有几千个AI工具，有升图的生视频的生文的乱七八糟的铺天盖地，所以他觉得很焦虑，就一直不敢行动。并且说现在很多人在讲AI编程，一听到编程也都被劝退了。

好，这两个极端的观点我认为都是有问题的，我来说一下我的理解。首先说AI不用选，呃，这里面有一个点是对的。就是现在AI的形态确实是你口喷表达你的诉求，然后AI帮你实现。但是这里我必须要强调的一个点，就是不是所有人都能表述清楚自己的需求的。首先跟你的表达能力有关啊，跟你的结构化思维有关。但我更想讲的还有一个点，就是你到底了不了解AI的能力边界，你到底了不了解怎么跟AH沟通。

这些基本的逻辑是一定要搞清楚的，所以他是需要学习的。只不过说前面AI底层逻辑的学习，你像在我的课程里面可能只需要七到十个小时就搞定了。它是一次学习，终身受用呢。然后接下来你需要不断的反复的跟你的cloud code cotest对对话去验证，去感受AI到底是一个怎么样的形态，它到底是怎么来接收你的啊需求的。

这个很重要，就是呃AI是学不会的，AI是用会的这是我的第一个观点。第二个其实我已经表达了，哎呀，有上千种工具，学起来特别焦虑，上千种工具，这是商业行为。你要知道天下内容一大抄，天下工具一大抄啊，所以你会看到阿里、腾讯、百度啊、字节他们出的工具其实都一样。你只要学会一个就行了，剩下都是举一反三的，他们的框架都大差不差。

所以我也不希望大家陷入到AI工具的焦焦虑里面。然后另外就是AI编程，AI编程这个概念，它的点不在编程上哦，一定是在AI上啊，所以我想跟所有想学AI的小伙伴，包括我那位粉丝想跟大家讲一下AI没有大家想的那么复杂。我也不希望大家去，因为AI这个事儿陷入到焦虑里面，一边焦虑一边想学，又怕学不会，这样来回反复，其实挺痛苦的。

好，第二个点是艺人公司，我自己本身就是一个艺人公司，创业者。呃，我从二零二五年的五月份到现在，我一直是一个创业的状态。我还有自己的艺人公司，社群带着一百六十六位伙伴一起在搞这个事情。那我想跟大家讲的是，我自己有一个公式叫艺人公司，等于AI加商业理解加自媒体IP这个公式里面，如果你让我说谁最重要是商业理解加自媒体IP真的不是AI，就是艺人公司它是分一个阶段的。

但是如果你想要真正的启动的话，一定不是因为你AI用的多溜，而是你真的看透了商业的本质，创业的本质以及当前普通人最大的一个杠杆自媒体。然后当你启动了之后，后面一个放大，你可以用AI去放大。比如说你赚到了自己的第一桶金，但是呢你想要往更高的一个level去突破的话，这时候你就需要第二个杠杆，就是AI.所以我真的想回应一下那位粉丝的问题。

就是如果你想搞艺人公司，如果你想搞所谓的自媒体副业的话，AI指示提效工具。这个一定要认识到，最重要的是你对这件事儿整体的理解。我认为不管AI有没有出现做公司这件事儿，创业这件事儿，底层逻辑从来都没有变过，就是MVP.然后迭代的心态嗯，不要追求确定性，也不要想着说我报一门课就能做副业，成功就能艺人公司成功，这个是违背商业逻辑的那今天为什么艺人公司大行其道啊？

第一个点，确实因为AI和自媒体的出现，让我们一个人拥有了组织级的能力。说白了就这这两杠杠杆，它真的能帮我们去撬动很多的资源。第二二点呢就是这么火的概念，现在经济环境也不好，很多人当然要宣传了，对不对？Ok以上就就我我这个视频的分享OK你对AI对艺人公司，对自媒体IP感兴趣的话，可以关注我。我日常会在我的短视频，或者我也会定时开直播去分享。

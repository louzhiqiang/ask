### 写作系统、表达与戒掉收藏

**观点**：收藏≠学习；要尽早建立「记录→整理→输出」的写作系统；用语音/口喷 + AI 访谈把灵感变成深度文章；表达欲是一人公司第一关。

**理由**：收藏是自我安慰；输出倒逼输入；朋友圈/短视频是低门槛练习场；AI 适合当访谈者帮你挖出已想明白但说不清的东西。

**可执行做法**：
- 戒掉无效收藏，定周期清理；把要学的立刻输出一条朋友圈/笔记

### Codex / 桌面端智能体工作流

**观点**：WorkBuddy 降低门槛，Codex/Claude Code 能力上限更高；真正拉开差距的是上下文质量 + Skill/SOP；要把高质量对话沉淀下来，用分叉避免上下文污染；剪辑等重活可做成 skill 闭环。

**理由**：工具会换，沉淀的 skill 与干净上下文可迁移；上下文超过一定占用易「降智」。

**可执行做法**：
- 主线任务开独立 session；支线用 fork/分叉
- 上下文升高时，让 AI 先写交接/沉淀框架再新开对话
- 业务文件夹当工作台；做完任务回看哪些可沉淀为 skill
- 剪辑：粗剪 skill → 人工选片 → 精剪 skill → 剪映

### AI 放大器与底层逻辑优先

**观点**：学 AI 学的不是追工具，而是用 AI 赋能业务的手感；AI 是放大器，前提是你不是零；显性知识好学，隐性手感只能自己趟。

**理由**：工具半年一变；最后一公里自动化极难；早进入深水区积累手感是优势。

**可执行做法**：
- 先学通识、模型边界、提示词，再按需学工具
- 用真实项目反复对话，专盯「最后一公里」
- 少收藏提示词，多沉淀自己的工作流

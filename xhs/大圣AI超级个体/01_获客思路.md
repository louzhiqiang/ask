# 01 获客思路（大圣AI超级个体）

**状态：初稿（基于已转写笔记+部分热评，全量转写完成后需更新）**

来源：主页人设与置顶、文字稿中的 CTA/产品叙事、热评意图。这是从「观点×痛点」与漏斗动作推导的获客拆解，不是博主官方文档。

## 1. 人设漏斗（Who → Trust → Offer）

| 层级 | 内容 | 证据 |
|---|---|---|
| 身份锚点 | 33 岁杭州程序员；西工大背景叙事；「AI 时代超级个体 / Coze 资深玩家」 | 主页；#3/#18/#71 经历开源 |
| 信任素材 | 亲自答疑无小助手、电子学会证书配套课、学员数（2300–2800 / 一人公司百人级）、零差评叙事、露脸口播 | #2；#1；#71 |
| 价值承诺 | 不教追工具，教「持续自学 + 判断 + 迁移到业务」的操作系统 | #2 核心价值观 |
| 筛选 | 649 可直接买；一人公司课必须 1v1 筛选；公开长视频自我筛选「想立刻赚快钱的不适合」 | #2 结尾；#71「不要去买那个三九八零…需要跟我一v一」 |

**漏斗形态**：公域短视频/直播（认知+信任）→ 置顶避坑/揭秘（筛选）→ 小店 649 或私信咨询 → 高客单一人公司 / 创始人 AI 陪跑 / 企业培训。

## 2. 内容钩子（公域获客弹药）

1. **反共识钩子**：一键自动化是坑（#33）、口播智能体没价值（#38）、别跟风 OpenClaw（#94）、证书别瞎考（#1）。
2. **选型对比钩子**：WorkBuddy vs Codex（#31，3197 赞）——降低「选错工具」焦虑，同时树立「底层逻辑老师」位。
3. **系统系列钩子**：「强烈建议建立写作系统」多条迭代（#97/#105/#111），用系列+置顶评论做追更与互导。
4. **结果展示钩子**：数字员工机房（#7）、Codex 剪辑闭环（#19/#64）、三场直播卖一万只答疑（#5）。
5. **经历开源钩子**：搬家/直播转化差/判断力人生决定（#28/#29/#18）——透明换信任。
6. **标题句式**：数字（2500人、3000会员、4–5 十数字员工）+ 普通人/老板 + 反问/命令（强烈建议、赶紧、一定要）。

## 3. 引流话术与 CTA 模式

- **软 CTA**：视频结尾「小店可买 / 找到我都可以」；「把行业岗位告诉我，我告诉你证书有没有价值」（#1/#2）。
- **硬筛选 CTA**：一人公司「先 1v1」；强调自己答疑、重构次数、加餐——用服务密度证明价格。
- **系列导流**：写作系统「看主页上一条」「置顶第二篇」「等飞书篇」——评论区作者高频指路（#105/#111）。
- **直播一体**：直播=卖课+答疑+切片素材（#3「一鱼多吃」；#5）。
- **争议承接**：遇「卖课吧」直接承认（#73「是呀」），把质疑变人设一致（自洽：做的=教的=卖的）。

## 4. 产品 / 课 / 咨询路径

```
路人
 ├─ 认知内容（超级个体/写作系统/反跟风）→ 关注
 ├─ 工具选型/避坑（#31/#1/#33）→ 信任「不乱推」
 ├─ 649 AI 社群（标品，橱窗）→ 规模获客与口碑
 ├─ 证书合作（锦上添花，非准入）→ 政企/简历场景增量
 ├─ 一人公司孵化（高客单+1v1筛选）→ 深度关系
 └─ 创始人 AI / 企业培训 / 数字员工陪跑（#7）→ 最高客单
```

定价与人数以口述为准（ASR）：649 社群；一人公司约 3980/4980；证书折扣代报名。

## 5. 可复用打法（给你做同类账号）

1. **自洽三角**：日常做的事 = 短视频选题 = 产品本身（#3/#28）。
2. **标品 + 一对多**：课/社群标准化；直播与短视频服务很多人（#34/#39）。
3. **先底层后工具**：所有爆款尽量落在「判断/系统/手感」，工具演示当证据不是主角。
4. **语料资产化**：咨询/直播录音 → AI 抽叙事卡 → 再变成短视频（#48）——获客内容工厂。
5. **Skill 化生产**：剪辑、海报、课介更新沉淀 skill，提高内容与销售物料产能（#19/#66）。
6. **评论区经营**：对行动型评论强激励（「坚持 30 天」）；对工具题给边界条件；对攻击用自洽短答。

## 6. 风险与问题（获客侧）

| 风险 | 表现 | 影响 |
|---|---|---|
| 卖课刻板印象 | 高赞评论嘲「卖铲子」 | 信任折损，需更多非销售结果案例 |
| 观点类「正确的废话」 | #107「说了点啥又没说」 | 需搭配实操切片平衡 |
| 工具更新极快 | WorkBuddy/Codex/龙虾轮动 | 旧视频过时；要用「底层逻辑」抗衰 |
| 广告前置反感 | #97「前一分钟全在说广告」 | 系列开头需更快给干货钩子 |
| 承诺边界 | 「不懂你的业务无法落地」（#2） | 诚实但劝退部分转化；可用「行业作业模板」补洞 |
| 平台依赖 | 获客几乎全靠短视频/直播 | 算法或限流会直接打收入周期（#29 已感知） |

## 7. 一句话归纳

**用「底层逻辑 + 真实一人公司过程开源」获信任，用「写作系统/选型避坑」做低门槛入口，用「649 标品规模化 + 高客单筛选」变现；AI 与自媒体是左右手杠杆，不是故事的全部。**

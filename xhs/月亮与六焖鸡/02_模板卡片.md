## 脚本模板 1｜糗事升华（短视频 2–5 分钟）

**适用**：旅行、运动、日常翻车，想要情绪和金句。  
**结构占比**：开场邀约 15% → 受苦过程 55% → 山顶/事后哲思 20% → 回家轻描淡写 10%。

```
【钩子】朋友/场景把我拖进一件「我以为很简单」的事。
【过程】用身体感受写惨：抽筋、想吐、后悔、还要硬撑面子。
【对照】看到一个小物（石缝小花 / 海 / 日出），或朋友随口一句。
【金句】把廉价爽感 vs 长期意义写清楚（多巴胺 vs 内啡肽）。
【回收】回家别人问怎么样——用一句玩笑把苦按下去，留给观众自己品。
```

**原作示例 #72**  
开场：「哥们儿说，给我上强度要爬大雁顶」→ 过程海拔爬升、胃痉挛 → 「人在天地间，就像蝼蚁」「久违的尝到了内啡肽的快感」→ 回家「开心了还能怎么样，总不能说一整天脚都在抽筋吧」。

## 脚本模板 2｜命名清单干货（短视频 2–4 分钟）

**适用**：存钱、预算、时间管理；要收藏和转发给「打工人」。  
**结构占比**：总规则 10% → 逐项命名 70% → 心态收束 20%。

```
【具象】把月收入说成 N 个硬币 / N 成。
【账户1】先拿走 X%——起名字（例：白日梦账户）——规定「只能用于____」。
【账户2…N】固定开支 / 自我投资 / 享乐……每个都命名。
【铁律】账户之间禁止交叉；钱不够就等，不许拆东墙。
【收束】「这不是数字问题，是心态/习惯问题」+ 一句前提（你得先相信存钱有必要）。
```

**原作示例 #52**  
「我每个月都会到账十个硬币」→ 白日梦 / 社畜 / 变强 / 多巴胺 + 应急小账户 →「不能交叉使用」→「财务规划其实并不是一个数字的问题，而是一个心态的问题」。

同结构可改写版：#14（自动转账「遗忘法」）、#70（松鼠症故事包装同一存钱观）、#32（有娃家庭版）。

## 脚本模板 3｜焦虑打补丁（3–8 分钟，保障/财务）

**适用**：保险、应急金、养老；有专业观察更好。  
**结构占比**：幻觉安全感 20% → 击碎 15% → 方案迭代 50% → 机制总结 15%。

```
【旧安全感】我以为 ____ 已经够了（团险/存款/百万医疗……）。
【击碎】一个真实事件或离职/政策变动，安全感没了。
【补丁1】上了方案 A，轻松了一阵。
【新漏洞】发现 A 解决不了 ____（垫资/等待期/一次性取用风险）。
【补丁2】改成 A+B 组合。
【再漏洞 / 再补丁】（可选第三轮）。
【结论】要的是「机制」不是单品：防返贫 / 现金流 / 落袋为安。
```

**原作示例 #55**  
同事白血病靠团险翻身 → 离职团险消失 → 百万医疗 → 担心垫资 → 重疾+百万 → 等待期问题 → 重疾+中端医疗 →「构筑家庭资产安全机制」。

同结构：#25（一坨退休金 vs 按月现金流）、#9（P2P/股市爽感 → 杠杆转回学习与确定性）。

## 脚本模板 4｜家人冲突 → 边界（长视频 7–12 分钟）

**适用**：催生、带娃、婆媳/父子；要共鸣和立场。  
**结构占比**：原话刺激 25% → 具体账 45% → 原则 20% → 修复动作 10%。

```
【原话】直接引用长辈刺人的一句（「带孩子不是很简单吗」）。
【现场】吵架/电话多长、自己睡眠/车程等数字。
【具体账】列 5–10 件「外人看不见」的琐事（作息、过敏、安全座椅上限……）。
【原则】一句话立场：愚孝 vs 负责；孩子不是投资；掀桌子才能和谐。
【修复】不彻底决裂——降温电话、寄点礼、话题隔离、保持距离。
【收束】「到我这为止」或「孩子成为他自己就够了」。
```

**原作示例 #3**  
父亲「带孩子不是很简单」→ 睡眠 3 小时 9 分钟、车程 5h vs 座椅 3h →「人是活在具体里的」「那叫愚孝」→ 事后寄米油哄老爷子 →「过去那些算不清的烂账，到我这为止就好了」。

同结构：#34（不让老人带娃的风险管理）、#2（发现自己变成父亲）、#1（回怼催生发家族群）。

## 30 秒口播填空（万能瘦身版）

> 适合把长文压成口播钩子。

```
以前我以为____。
直到发生____，我才发现____。
所以真正重要的不是____，而是____。
```

套用检查：#66（以为变强→发现自卑）、#22（以为努力就能搞钱→无为空白让财富流动）、#9（以为投资实力→杠杆是大脑）。

## 使用注意（防踩坑）

1. **模板 2、3 要有自己的真实数字**，不要抄他的「十个硬币/90%」比例。  
2. **模板 4 必须有「修复动作」**，否则只剩发泄，和他账号「爱之深」气质不符。  
3. 他的保险专业细节、香港产检、客家风俗**不要硬编**；借结构，换你的生活现场。  
4. 反讽体（#59）难演，除非语气能撑住「假装躺平」，否则易被当成真躺平。

# AI时代，我们应该如何学习？

## 简介
想学好任何东西，先忘掉学校教的那一套。不要“先学后做”，而要“先做后学”。你不是因为变强了才能去产出，你是通过不断产出才慢慢变强的

## 文字稿
今天这个内容来自我在推特上的一篇三百多万浏览的文章。我把中文版给大家念一下，想学好任何东西，要先忘掉学校教的那一套。最近一位国内的朋友问我，怎么提高英语，学生时代，他就英语不好作，给自己贴了一个美语言天赋的标签。现在为了职业发展，想再努力一把，可就是坚持不下去。我问他是怎么学的？他说他买了语法书发音课，词汇表正在拼命背呢。

我说为什么这么学？他说，因为我得打好基础系统的学问题就出在这儿。即使毕业多年了，他身上那股学生思维还没有退去，教育体制给我们洗了脑，让我们觉得学习就必须是系统的、自下而上的教材驱动的。我告诉他成年人可不能这么学，相反你应该去找你本来就感兴趣的英文内容，遇到不懂的就查字典，或者让AI去给你讲解，从这些内容里去记单词。

先定义学英语的目的，他是一个沟通和理解的工具，然后再倒推怎么学，你想理解什么，你就去读什么，把那个东西当成你的教材。作为成年人，我们需要把学生时代的学习方法法来一个一百八十度大转弯。在学校里，你是从基础开始往上爬，学到的东西可能过好几年才能用得上，但是接触往往是最枯燥的。如果成年人还这么学，早晚得半途而废。

成年人应该反着来，先找到现实中要解决的问题，搞清楚。为了解决这个问题，你需要学什么知识，然后再倒回去学AI，极大的加速了这个过程。只要你知道怎么提问，他就是一个二十四小时在线的世界级的导师，能回答任何问题，我自己就有这种体会。几年前我想提高技术能力，尝试学点编程，然后就去看CS入门讲座。结果很快就放弃了，因为我没有办法把那些内容和我现实生活中的需求联系起来。

去年我开始使用clck code code x这些AI编程工具，我用大白话描述我的产品想法，很快它就变成了可以运行的产品。每次当想法变成现实，我都觉得非常的兴奋，很有成就感。以前满屏的代码看的我头疼，总觉得自己不行。而现在代码在我眼里只是实现目标的手段。我会让AI带着我梳理代码库的结构，告诉我每个文件是干嘛的，各个部分是怎么串起来的，并且加上详细的注释，做了几个项目之后，我学到的编程知识比听一年大学讲座还多。

虽然这并不系统，但是我又不是要转行当工程师，我只是想提升我的技术素养，把代码变成解决问题的工具。为什么成年人应该逆向学习？第一，学生的正直就是学习，而成年人要上班上一天班，累个半死，谁还有精力去听那些枯燥的课？第二，学生是不得不学，教育体系，会确保你学习考试、作业出勤等等。而成年人学习纯粹是个人选择，没有人逼你这意味着要想坚持下去，就得靠内在动力。

如果你觉得没意思，你就会放弃。第三，学生的目标很明确，考个好成绩。但是成年人必须自己定义目标，否则动力很快就会枯竭。所以核心逻辑在于，对于成年人来说，保持动力是学好任何东西的关键。因为学习不是一朝一夕的事儿。所以如果你想学点什么东西，先从一个问题或者一个项目开始搞清楚，要完成什么任务，然后倒推回去学，这样学习才会变得有趣，也才能坚持下去。

忘掉先学后做，先做后学，你不是因为变强了才能去产出，你是通过不断产出才慢慢变强的。

## 账号速览

### 定位

「做一人公司的 AI 创业者」×「每天啃一手英文信息的 AI 课代表」。他把硅谷大佬的播客、长推文、技术博客，以及新模型、新 agent 工具，翻成中文的「三个启发 / 四个观点」，再夹一句「我自己做企业 AI 服务 / 做产品的体会」。立场是**实干的同行者 + 信息搬运工**，不是技术教授，也不是情绪博主。

## 一、思路构建：「替你啃完一手信息 → 拆成 N 点 → 落到你我能做什么」

### 1.1 典型推演链

**一条新闻或一期大佬内容 → 为什么值得看（人物背书 / 数据震撼）→ 「我帮你提炼了 N 个观点」→ 逐点：原观点 + 人话解释 + 一个例子 → 结合我自己做一人公司 / 企业 AI 服务的体感 → 一句升华判断 → 固定结尾**

| 环节 | 做法 | 证据 |
|---|---|---|
| 钩子 | 新闻、数据或大佬名 | #3「他们一张卡一个小时，即使在最低价的时段也能收入三十八美元」；#60「一个汉堡消耗的水啊，相当于你用AI，可以用六百六十八年」 |
| 背书 | 先把人物立起来 | #2「他可能是华尔街唯一一个既能看懂财务报表，又能看懂火箭发动机跟GPU芯片的投资人」；#80 列出 Karpathy 的「五点」 |
| 预告结构 | 「聊了 N 件事 / 提炼了 N 个观点」 | #2「他聊了四个当下AI领域最核心的话题」；#80「我帮大家提炼了四个非常有价值观点」；#54「它一共聊了四件事情」 |
| 逐点人话化 | 「什么意思呢？」+ 类比 | #107「什么意思呢？我们拿目前世界上最成功的、最赚钱的AI应用cursor来举例子」；#2「就有点像去看一个十岁的小孩子，然后试图去预测他三十五岁能达到什么成就」 |
| 自己的体感 | 插入一人公司、做产品经验 | #36「很多朋友呢都知道我是做艺人（一人）公司的，每周都会跟大量对话」；#89「我呢也想结合自己开发AI产品的经验」 |
| 升华 | 一句可截图的判断 | #2「知识可能更像水，你越想去封堵，它它就会越找到这个间隙去流动」；#10「大模型的能力不会消除无知，但会抬高无知的这种代价」 |

### 1.2 论证方式

1. **权威转述 + 筛选（主力）**：他不发明观点，而是挑观点、排顺序、翻成人话。
   - #107「一般的大佬跟大神之间的区别就是能不能用人话，普通人听得懂的语频（言），把深奥的道理讲清楚」——这句话也是他对自己的要求。
   - #44「我知道大家肯定懒得去看啊，所以呢这期视频我就帮你们提炼出了里面最有价值信息」（Anthropic 244 页系统卡）。
2. **数学 / 数据算账**：用一个简单算式把结论钉住。
   - #89「百分之九十五的二十次方，只有百分之三十六」。
   - #11「一万亿token大概需要五百万美元。但如果便宜一千倍……大概是五千美元左右」。
3. **反常识立论**：先树一个大众共识，再推翻。
   - #87「我先抛一个观点啊，就是千万别碰大众刚需」；#69「全网都在吹AI手机，但我要泼几盆冷水」；#96「你所知道的AI智能体百分之九十九都不是智能体」。
4. **亲身实验 / 实测**：自己跑一遍再讲。
   - #46「我用质普（智谱）新推出的GIM五点一大模型啊，持续不断的工作了六个小时……中间经过了二十多次的commit」；#91「这是我六十块钱买的聊天机器人。你好，小智帮我点一杯咖啡」。
5. **创业连续剧**：「一年 30 个 AI 应用」按期推进、按期复盘。
   - #120 第一期 → #119 教学篇 → #113 / #111 第二期随手记 → #103 第三期「帮你回」→ #105「前两期产品复盘和揭秘」→ #85「我的产品被腾讯下架了」→ #32「一年30个产品翻车」。

### 1.3 开头钩子类型

- **「今天…」直接点题（最多）**：「今天要给大家强烈强烈推荐一期博客」（#2）；「今天来讲，如何让你的智能体能够长时间的运行任务」（#46）；「今天我们来聊一个很反常识的话题」（#86）。
- **大佬 / 机构新动态**：#53「Cloud code核心开发者啊最近发了两篇技术博客」；#22「接下来跟大家分享一份YC刚放出来的AI创业手册」；#18「一家管理过上千亿美元资产的基金公司啊，内部到底是怎么使用AI的」。
- **惊人数字**：#3（38 美元一张卡）、#5「团队十四个人零营销费用日增长百分之十」、#60（汉堡 vs 668 年）。
- **反问 / 泼冷水**：#89「今天我要给大家泼一盆冷水」；#40「大家有没有见过四万亿美元公司老板生气的样子啊」；#9「在干嘛呢？过家家呢？是不是一个个都在装什么装啊？」
- **个人事件**：#1「今天跟大家分享个事儿啊」；#85「我开发的两个产品被腾讯封了」；#43「朋友们啊，这波咱们可是出席啊央视财经频道」。

很少做「大家好我是…」式开场：只在 2025-03 前后几条出现（#146「大家好，我是第四种黑猩猩的李超」、#103），之后把自我介绍挪到结尾。

### 1.4 结尾类型

- **固定签名尾（主型）**：「好了，今天视频就到这里了，我是第四种黑猩猩李超，我们下次见。」182 条里「我们下次见」出现在 113 条；B 期起几乎每条都用（B–E 期 121/132 条）。例：#2「好了。今天视频就到这里了，我是第四种黑金（黑猩猩）李超，我们下次见。」
- **升华判断收**：#10「大模型的能力不会消除无知，但会抬高无知的这种代价」；#53「你塞的越多，agent反而越受限，你给的越克制呢，它发挥的反而会更好」。
- **推荐原片**：#80「我觉得大家一定要自己去看一下这个完整的博客」；#40「非常强烈的推荐大家去看一下这个原视频啊，真的太精彩了」。
- **抛问题给评论区**：#7「那你觉得AI的下一个交互入口会是什么呢？」；#91「你日常的工作生活中有什么重复性的劳动……可以在底下的评论区留言告诉我」。
- **挖坑预告**：#82「让他觉得说大模型让我们走进了一个新的死胡同呢？我们下一期详细来聊」（下一期即 #77）；#80「这个呢我在这里先挖一个坑」。

点赞号召只在 22 条里出现，远少于 404 那类「点赞收藏关注」强导流；他也几乎不导私域（偶有 #113「公众号」）。

## 三、对话特点

### 3.1 语气

- **稳、平、像同事在会议室里讲**，很少毒舌或爆粗。典型句：#26「我觉得这期视频呢可能会对你有些帮助」；#56「这个视频里面呢我只是抛砖引玉，跟大家讨论一下」。
- **兴奋只给大佬**：#54「写的实在太好了，就是直接起鸡皮疙瘩的那种」；#80「感觉像一部悬疑电影一样精彩」；#2「强烈强烈推荐」。
- **偶尔吃瓜嘲讽**：#9「一帮千亿富豪啊，内帮（像）过家家一样，一个个都不知道在装什么装」；#3「你说气不气？」；#92「朋友们，我真的有点看吐了」。
- **谦逊收口**：#88「好了，我说完了，我说的不一定对」；#57「你可能呢不一定认同」。

### 3.2 人称与对话对象

182 条合计：「我」约 4135 次、「你」约 2615 次、「我们」约 1720 次、「大家」约 605 次。「我」明显多于「你」（约 1.6:1），**叙述者姿态**比 404 那类「对着你说」更强；但「我们」用得很多，常把自己和观众放进同一阵营（#87「但我们不一样啊，我们艺人（一人）公司呢或者说超级个体啊，没有这么多子弹」）。

对话对象：

1. **「大家 / 朋友们 / 同学」**：「朋友们」只在 16 条出现，比 404 少；他更常用「大家」和「你」。
2. **假想提问者**：#87「有些人可能会问啊，就是说老哥啊，你是不是说反了所有的商业教科书啊」；#89「我知道你可能在想什么，是不是可以改一下提示词」。
3. **评论区与私信**：#21「评论区问的最多的问题呢」；#116「很多粉丝都私信我说」；#138「越来越多的朋友开始问我这些问题」。
4. **一人公司 / 中小老板**：#65「尤其是像我这种小企业啊，我就一人公司」；#68「我真心建议很多中小型的卖家」。

### 3.3 中英夹杂程度

- **轻度到中度，以术语为主**：agent、coding agent、context engineering、token、scaling、FDE、MCP、progressive disclosure。基本不整句说英文。
- 常见「英文术语 + 中文解释」：#78「上下文工程，叫做context engineering.简单来说啊……」；#53「progressive disclosure.什么意思呢？中文翻译后来就是渐进式的披露」；#86「规模化，英文叫做scale」。
- 大量人名 / 产品名是 ASR 错字重灾区（卡帕西、卡巴奇、capacity 都指 Karpathy），说明他口头英文发音偏中式，并不刻意「洋气」。

## 四、是否有模板

### 判断：**有，而且是强模板。B 期之后约八成视频套在三套结构里，开头「今天…」、结尾签名句几乎固定**

B–E 期 132 条视频里，大约 105 条能归进下面三套之一；固定签名尾出现在 121 条。变量只有「素材来源」（大佬内容 / 新工具 / 自己的项目）和「N 是几」。A 期的 1 分钟快讯和少量 vlog（#43 央视、#93 谷歌大会、#123 粉丝破 5 万）不套模板。

### 模板 A｜大佬内容解读：「X 的 N 个启发 / 观点」

- **步骤**：① 一句话立人物（「如果只能看一个人……」「唯一真神」）② 交代来源（哪期播客、多长、我看了几遍）③ 「我帮你提炼了 N 个观点」④ 逐点：原话 → 「什么意思呢」→ 例子 → 我的体感 ⑤ 一句升华 ⑥ 「推荐去看原片」+ 签名尾
- **时长占比（约）**：人物 15% / 来源 5% / 逐点 65% / 升华 + 推荐 15%
- **代表**：#2（9660）、#107（6849）、#80（5343）、#129（4561）、#70（2192）、#54（1907）、#50、#58、#118、#131
- **证据句**：#107「如果只能看一个人的视频学习AI，我会推荐andrew capacity」→「最近呢他又一一演讲讲爆全网，他提出了三个非常有意思的观点。第一啊……什么意思呢？我们拿目前世界上最成功的、最赚钱的AI应用cursor来举例子……我自己也是科特（Cursor）的付费用户」→「大家如果有兴趣的话，可以自己去网上找一下这个演讲的这个完整的视频」→ 签名尾

### 模板 B｜工具 / 模型实测：「为什么 X 值得用 + 我跑了一遍」

- **步骤**：① 痛点或新品（「很多朋友都在纠结……」）② 一句话定位（它跟别人不一样在哪）③ 我的实测过程（跑几小时、几次 commit、截图）④ 原理拆解 2–4 点 ⑤ 适合谁 / 怎么选 ⑥ 签名尾
- **时长占比**：痛点 10% / 定位 10% / 实测 40% / 原理 25% / 建议 + 结尾 15%
- **代表**：#53（2951）、#29（2488）、#59（2154）、#46（2050）、#21（2025）、#38（1943）、#91（1873）、#52、#35、#33、#6
- **证据句**：#46「我用质普新推出的GIM五点一大模型啊，持续不断的工作了六个小时，完成了一个功能完整的多人协作白板……那具体是怎么来做的呢？这个视频啊我会一步一步的跟大家分享智能体长任务呢有什么难点，解决方案是什么」→「更重要的是啊朋友们……它竟然还是个开源模型」→ 签名尾

### 模板 C｜一人公司 / 产业判断：「反常识观点 → 数学或案例论证 → 给超级个体的建议」

- **步骤**：① 泼冷水或反常识判断 ② 「这不是 X 的问题，而是 Y」③ 一个算式或一篇外网文章 / 一家公司案例 ④ 拆 N 条原因 ⑤ 「我们一人公司应该怎么办」⑥ 升华 + 签名尾
- **时长占比**：立论 15% / 论证 35% / N 条 30% / 建议 + 升华 20%
- **代表**：#89（3798）、#87（1752）、#90（1772）、#83（974）、#86、#69、#96、#60、#57、#11、#4
- **证据句**：#89「今天我要给大家泼一盆冷水……这不是哪家技术强，哪家技术弱的问题，而是一个基本的数学原理」→「百分之九十五的二十次方，只有百分之三十六」→「我们这种啊利用AI想去搞事业的人，应该如何去看清这些真相」→「AI去处理复杂性，人类去掌握控制权，这才是AI智能体」→ 签名尾

## 六、可借鉴与不可复制

### 可借鉴

1. **人物背书型选题**：盯住 Karpathy、Levels、Gavin Baker、Ilya 这类「出一期必看」的人，第一时间做中文解读（#107 #80 #2）。
2. **N 点结构 + 「什么意思呢」**：每个观点都给一句人话翻译和一个例子，观众容易收藏。
3. **固定签名尾**：「好了，今天视频就到这里了，我是 XX，我们下次见」，不导流也能形成辨识度（113 条）。
4. **一个公开挑战做起号**：「一年 30 个 AI 应用」带来 #1、#111、#119 三条千赞以上，还引来投资人（#1）。
5. **反常识 + 简单算式**：#89 的 0.95²⁰ 就是一条视频的全部论证骨架。
6. **放弃没用的形式**：A 期 1 分钟搬运中位 36 赞，他果断转 4–7 分钟深读，均赞涨了十几倍。

### 不可复制（或很难复制）

1. **一手英文信息的阅读量**：几乎每周啃完 2–5 小时的英文播客和长文（#129「三个半小时」、#80「两个半小时」）。
2. **真实的一人公司和企业 AI 服务经历**（#26 #43），以及被红杉投资人、央视找上门的背书（#1 #43）。
3. **账号名自带的哲学钩子**：「超级智能是不是第四种黑猩猩」，一次性的命名红利。
4. **爆款时间窗**：Karpathy、Levels 这类内容在国内第一批解读才吃到红利，后来者会面对同质化。
5. **挑战系列的诚实翻车**（#32 #85）：需要真的做了、真的失败，才能讲得可信。

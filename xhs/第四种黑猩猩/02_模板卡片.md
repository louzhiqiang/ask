## 脚本模板 1｜大佬内容解读「X 的 N 个启发」（4–7 分钟）

**适用**：顶级人物的新播客、演讲、长推文、技术博客；最容易出爆款。
**结构占比**：立人物 15% → 来源 5% → N 个观点 65% → 升华 + 推荐原片 15%。

```
【立人物】如果只能看一个人的____，我会推荐____。他是____（两三个硬核头衔）。
【来源】他最近上了____的播客，长达____小时，我看了好几遍。没时间看的话，看我这个视频就够了。
【预告】我帮大家提炼了____个最有价值的观点。
【观点×N】第一____。什么意思呢？我们拿____来举例子……我自己做____的时候也有同感：____。
           第二____……第三____……
【升华】总结来说，____（一句比喻或判断）。
【结尾】大家有兴趣的话一定要自己去看一下完整的____。好了，今天视频就到这里了，我是____，我们下次见。
```

**原作示例 #107（6849 赞）**
「如果只能看一个人的视频学习AI，我会推荐andrew capacity（Karpathy）」→「他是open AI的创始成员之一，他也是特斯拉自动驾驶和AI部门员的总负责人」→「他提出了三个非常有意思的观点。第一啊……什么意思呢？我们拿目前世界上最成功的、最赚钱的AI应用cursor来举例子……我自己也是科特（Cursor）的付费用户」→「大家如果有兴趣的话，可以自己去网上找一下这个演讲的这个完整的视频去看一下」→ 签名尾。

同结构：#2（Gavin Baker 四个话题）、#80（Karpathy 四个观点）、#129（Levels 七个启发）、#70（Ilya）、#54（Karpathy 推文四件事）。

## 脚本模板 2｜工具 / 模型实测「我跑了一遍，告诉你为什么值得用」（5–20 分钟）

**适用**：新 agent、新模型、vibe coding 工具栈；吸引想上手的普通人。
**结构占比**：痛点 10% → 定位 10% → 实测 40% → 原理 25% → 怎么选 + 结尾 15%。

```
【痛点】很多朋友都在纠结____ / 评论区问得最多的是____。
【定位】____是____里最特别 / 最冷门的一个，因为它____（不是写代码，而是____）。
【实测】我用它连续跑了____小时 / 做了一个____，中间____次 commit，完全没有插手。
【原理】那具体是怎么做到的？第一____；第二____；第三____（配原文或截图）。
【怎么选】如果你是____，选____；如果你是____，选____。
【结尾】更重要的是____（开源 / 免费 / 普通人也能用）。好了，今天视频就到这里了，我是____，我们下次见。
```

**原作示例 #46（2050 赞）**
「今天来讲，如何让你的智能体能够长时间的运行任务。我用质普（智谱）新推出的GIM五点一大模型啊，持续不断的工作了六个小时，完成了一个功能完整的多人协作白板，中间经过了二十多次的commit，然后近三十次的功能迭代，完全没有插手」→「智能体长任务呢有什么难点，解决方案是什么」→「更重要的是啊朋友们，在有这些强大能力的情况下，它竟然还是个开源模型」→ 签名尾。

同结构：#53（Claude Code 渐进式披露）、#29（Pi Agent 21 分钟）、#59（vibe coding 工具栈）、#21（Pi vs Claude Code）、#38（爱马仕 vs 小龙虾）、#35（四模型对比）。

## 脚本模板 3｜反常识判断「泼一盆冷水 → 一道算术 → 给超级个体的建议」（3–7 分钟）

**适用**：产业趋势、一人公司方法论、热点泡沫；转发率高。
**结构占比**：立论 15% → 论证 35% → N 条原因 30% → 建议 + 升华 20%。

```
【立论】今天我要给大家泼一盆冷水：____注定____ / 千万别碰____。
【纠偏】这不是____的问题，而是一个基本的____（数学原理 / 商业逻辑）。
【论证】前两天在外网看到一篇____（作者背书）。算一道题：____（如 95% 的 20 次方 = 36%）。
【原因×N】第一____；第二____；第三____。
【建议】那我们这种用 AI 搞事业的人 / 一人公司应该怎么办？____。
【升华】____（一句对仗的判断）。好了，今天视频就到这里了，我是____，我们下次见。
```

**原作示例 #89（3798 赞）**
「今天我要给大家泼一盆冷水……这不是哪家技术强，哪家技术弱的问题，而是一个基本的数学原理」→「前两天呢刚刚在外网上面翻到这篇高质量的爽（长）文，是一个今年开发了十二个智能体的国外大佬写的」→「百分之九十五的二十次方，只有百分之三十六」→「AI去处理复杂性，人类去掌握控制权，这才是AI智能体」→ 签名尾。

同结构：#87（别碰大众刚需）、#90（相变）、#69（AI手机不合理）、#96（99% 不是智能体）、#60（汉堡的水）、#83（AI 会不会固化阶级）。

## 脚本模板 4（低频）｜公开挑战连续剧「一年 N 个 X」（2–8 分钟）

**适用**：起号、积累真实故事；每期都是下一期的钩子。

```
【口号】挑战一年完成____个____，看看哪个会真的____？今天是第____期。
【演示】先看效果：____。
【灵感】我唯一的要求就是我自己真正会用的工具。
【搭建】我是怎么做的：____（三步）。
【数据】一天之内已经有____个用户 / 上期视频涨了____粉。
【预告】按照惯例，后续我会把思考和开发过程分享给大家；你希望我挑战什么方向，评论区告诉我。
```

**原作示例 #111（2818 赞）**
「挑战一年完成三十个AI应用第二期。第二个应用黑猩猩随手记发布。一天之内呢已经有超过两百个用户注册使用了」→「我唯一的要求就是我自己真正会用的工具」→「我在微信上建了三个群」→ 签名尾。后续：#105 复盘、#85 被下架、#32 承认「翻车」。

## 30 秒口播填空（万能瘦身版）

```
____（大佬名）最近说了一句话：____。
什么意思呢？就是____。
我自己做____的时候也发现：____。
所以对我们普通人来说，____。我是____，我们下次见。
```

## 固定开头和结尾（照抄就能形成辨识度）

- **开头**：「今天来跟大家聊 / 分享____」或「____最近发了____」，不做自我介绍。
- **结尾**：「好了，今天视频就到这里了，我是第四种黑猩猩李超，我们下次见。」（182 条里 113 条以「我们下次见」收尾，2025-04 后几乎每条都有。）

## 使用注意（防踩坑）

1. **模板 1 的命门是「挑人」**。只有 Karpathy、Levels、Gavin Baker 这一档才爆；普通高管访谈（#109 皮柴 220、#114 Altman 119）表现平平。
2. **别只做新闻复述**。A 期 53 条快讯中位只有 36 赞；没有「我的体感」和「N 点结构」，就是搬运。
3. **模板 2 要有真实实测**。#46 的「六个小时」「二十多次 commit」才是可信度来源；商单式测评（#75 #65 #84）赞明显偏低。
4. **时长别无限拉长**。Top10 九条在 4–7 分钟；E 期平均 7.5 分钟后均赞回落到 659。
5. **挑战系列要能扛住翻车**。他在 #85 #32 公开承认停更和翻车，反而保住了信任；只报喜不报忧的挑战难以为继。
